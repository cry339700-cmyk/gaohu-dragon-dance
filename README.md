- **编辑与导出**：编辑保存到当前浏览器，不会自动同步或修改公开站点。

这是静态部署副本。GitHub Pages 从 `main` 根目录发布，`.nojekyll` 禁用模板处理。网页和素材请保持相对路径，尤其是 `assets/` 与 `fulonger.html`。

## 加载优化

展馆先显示可交互内容；字体、图片和模型从同源路径分开加载，舞龙背景视频等首屏完成后再启动。福珑儿仍只在打开弹窗时请求模型和素材。下载离线 HTML 时才重新打包展陈资源。旧版哈希资源暂时保留，供浏览器缓存的旧网页使用。
